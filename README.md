# 🇵🇹🇪🇸 포르투갈 & 스페인 효도 여행 웹 가이드
어머니와 함께하는 14박 15일 모바일 일정표 및 가계부 웹 애플리케이션입니다.

## 🚀 GitHub Pages 배포 가이드
1. 이 저장소(Repository)의 루트 디렉토리에 `index.html` 파일이 업로드되어 있는지 확인합니다.
2. 상단 메뉴의 **Settings** -> 좌측 사이드바의 **Pages**로 이동합니다.
3. **Build and deployment** 항목의 설정:
   - **Source**: `Deploy from a branch`
   - **Branch**: `main` (또는 `master`) / `/ (root)` 선택 후 **Save** 클릭
4. 약 1~2분 후 상단에 생성된 전용 웹 주소(`https://<아이디>.github.io/<저장소명>/`)를 확인합니다.
